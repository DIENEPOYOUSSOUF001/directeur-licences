DIRECTEUR - SITE DE SUIVI DES LICENCES (site Netlify independant, via GitHub)
=============================================================================
Contenu du depot (a mettre tel quel a la RACINE du depot GitHub) :
  index.html                      tableau de bord en direct
  netlify.toml                    reglages Netlify
  netlify/functions/licence.mjs   recoit les rapports du logiciel + commandes admin
  netlify/functions/package.json  dependance @netlify/blobs

1) GITHUB (nouveau compte)
   - github.com > Sign up > creez le compte et confirmez l'e-mail.
   - New repository > nom : directeur-licences > Private > Create.
   - "uploading an existing file" > glissez index.html, netlify.toml et le dossier netlify
     (si le dossier ne passe pas : Add file > Create new file, tapez
      netlify/functions/licence.mjs puis collez le contenu ; idem package.json) > Commit changes.

2) NETLIFY (nouveau compte)
   - app.netlify.com > Sign up > "Sign up with GitHub" (utilisez le nouveau compte GitHub).
   - Add new site > Import an existing project > GitHub > directeur-licences > Deploy.
   - Site configuration > Change site name (ex : directeur-gmi).
   - Site configuration > Environment variables > ADMIN_KEY = mot de passe long (20+ car.)
   - Deploys > Trigger deploy > Deploy site.

3) OUVRIR  https://VOTRE-SITE.netlify.app  et saisir ADMIN_KEY.

4) DANS DIRECTEUR.xlsm  (Alt+F11 > Edition > Remplacer > Projet actif)
   remplacer  https://gmidy0.netlify.app/.netlify/functions/licence
   par        https://VOTRE-SITE.netlify.app/.netlify/functions/licence
   (ne pas toucher au simple texte gmidy0.netlify.app)

TEMPS REEL : le tableau se rafraichit tout seul (5/10/30/60 s au choix).
Une machine apparait "en ligne" si elle a envoye un rapport il y a moins de 5 minutes ;
cela suppose que le logiciel envoie un signal regulier (voir les explications de Claude).
